# Official HLF QR Code Asset

Place the official HLF UPI QR Code image here with the filename:
`hlf-upi-qr.png`

Path: `assets/hlf-upi-qr.png`

If this image is not present, the website automatically falls back to generating a crisp, high-resolution UPI payment QR code directly using the official UPI payment intent (`upi://pay?pa=...&pn=...&am=50&cu=INR&tn=HLF%202026%20Registration`).
You can also configure the QR code image path or upload it anytime from the HLF Admin Portal under Settings.
